## 👋 Sobre mí

Soy **Tecnólogo en Análisis y Desarrollo de Software (SENA)** y construyo aplicaciones web y móviles que se usan en producción.

- 📱 Desarrollo apps **móviles híbridas y nativas** con React Native y Java (Android).
- 🌐 Construyo **sistemas web** en PHP con el framework CodeIgniter.
- ☁️ Trabajo con **Firebase**: bases de datos en tiempo real, autenticación y servicios en la nube.
- 🤖 Automatizo procesos con **Python**, integración de **IA** y manejo de archivos Excel.
- 🛠️ Tengo experiencia en **soporte técnico**, así que entiendo tanto el código como la operación del negocio.
- 🌱 Ahora mismo estoy fortaleciendo mi **inglés** y profundizando en arquitectura de aplicaciones.
